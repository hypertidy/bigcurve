# Package index

## Densify

Insert vertices along great circle arcs where a target projection bends
them, for paths, segment meshes and wkpool vertex pools.

- [`densify()`](https://hypertidy.github.io/bigcurve/reference/densify.md)
  : Adaptively densify lines for a projection

PROJ, and a Lambert azimuthal equal area string.

- [`segment()`](https://hypertidy.github.io/bigcurve/reference/segment.md)
  : Segment
- [`rproj_xy()`](https://hypertidy.github.io/bigcurve/reference/rproj_xy.md)
  : Transform coordinates
- [`laea()`](https://hypertidy.github.io/bigcurve/reference/laea.md) :
  Projection string
